# Reflexão Ética: Uso Responsável e LGPD

Usar um modelo de linguagem para classificar notícias exige cuidados que vão além da acurácia. O primeiro é a transparência: cada classificação deve vir acompanhada de uma justificativa e de um nível de confiança, permitindo que usuários e auditores entendam por que uma notícia recebeu determinado rótulo. Também é necessário informar de forma clara que a categorização é feita por IA, documentar os critérios adotados e manter registros das decisões para eventual contestação.

O segundo cuidado é o viés. Modelos aprendem padrões dos dados de treinamento e podem associar termos a categorias de forma enviesada, por exemplo, classificar como "Política" toda notícia que cite um partido ou grupo social, ou tratar temas de determinadas regiões ou comunidades de maneira desigual. Para mitigar isso, o prompt adota critérios objetivos baseados no tema, proíbe juízos de valor e usa exemplos equilibrados. Ainda assim, é essencial avaliar periodicamente os resultados por categoria, revisar amostras com pessoas diversas e encaminhar casos de baixa confiança para revisão humana.

O terceiro cuidado é a proteção de dados. Notícias frequentemente contêm nomes, idades, endereços e até informações de saúde, que a LGPD classifica como dados pessoais ou sensíveis (art. 5º). Pelos princípios da finalidade e da necessidade (art. 6º), o sistema deve tratar apenas o necessário para classificar: anonimizar ou mascarar dados pessoais antes do envio ao modelo, não reproduzi-los nas saídas, evitar armazenar textos completos sem necessidade e verificar se o provedor da API não reutiliza esses dados para treinamento. Assim, a IA atua como ferramenta de apoio, responsável e auditável.
